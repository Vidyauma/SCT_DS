# Decision Tree Classifier - Bank Marketing Dataset

## Objective
Predict whether a customer will subscribe to a term deposit using demographic and behavioral data.

## Dataset
Bank Marketing Dataset (UCI Repository)

## Libraries Used
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Steps
1. Load dataset
2. Encode categorical variables
3. Split data
4. Train Decision Tree Classifier
5. Evaluate model
6. Visualize decision tree
7. Plot feature importance

## Accuracy
Around 89%
