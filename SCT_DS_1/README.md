# World Population Data Analysis

This project was completed as part of the **SkillCraft Technology Data Science Internship – Task 01**.

## Objective

The aim of this project is to perform Exploratory Data Analysis (EDA) on the World Population dataset using Python. The project displays dataset information, checks for missing values, summarizes statistics, and visualizes population trends through different charts.

## Dataset

- **Dataset Name:** world_population.csv
- The dataset contains population statistics of countries around the world along with information such as continent, capital, area, density, growth rate, and population for different years.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn


## Analysis Performed

The program performs the following operations:

- Loads the dataset
- Displays the first five rows
- Shows dataset information
- Displays summary statistics
- Checks for missing values
- Lists the top 10 most populated countries
- Displays the number of countries in each continent
- Generates visualizations for:
  - Top 10 populated countries
  - Population distribution (Histogram)
  - Countries by continent

## Output

### Console Output

- Top 5 rows of the dataset
- Dataset information
- Statistical summary
- Missing values
- Top 10 populated countries
- Countries by continent

### Graphs

The program displays:

- Top 10 Most Populated Countries (Bar Chart)
- Population Distribution (Histogram)
- Countries by Continent (Bar Chart)

## Conclusion

This project demonstrates the use of Python libraries such as Pandas, Matplotlib, and Seaborn for data analysis and visualization. The analysis provides insights into population distribution and country-wise population statistics across different continents.
